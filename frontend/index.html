About this project

A library you can actually use.

OpenShelf is a student-built catalogue that helps you discover books you can legitimately read for free. Every title listed carries its source URL and license so you can verify its availability yourself.

Books come from public-domain collections (Project Gutenberg, Standard Ebooks) and open-licensed publishers. We do not list a title simply because a PDF happens to exist online — we check the license.

Catalog fields follow the ISBD "areas" (Area 0 through Area 8), which is the framework librarians use to describe books.

The Study with AI view is powered by a server-side language model. It is grounded in each book's catalog record so it can help you understand, compare, and summarize — without inventing sources or facts.
